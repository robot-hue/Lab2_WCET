# Лабораторная работа №2 по СРВ

Оценка наихудшего времени выполнения (WCET) фрагмента программы с учетом архитектуры процессора.
Вариант: **«Шаг ПИД-регулятора с фильтрацией входного сигнала»**.

Консольное приложение на Python 3.10+ (разработано на 3.12) с использованием неизменяемых моделей данных (dataclasses).

## Что делает программа
- вычисляет лучшее время выполнения операции (BC_i) при идеальном кэш-попадании и верном предсказании перехода;
- вычисляет худшее время выполнения операции (WC_i) с учетом заложенных штрафов процессора за промахи кэша и сбросы конвейера;
- суммирует по всему фрагменту наилучшее время выполнения (BCET) и наихудшее время выполнения (WCET);
- рассчитывает коэффициент недетерминизма системы как отношение K_нд = WCET / BCET;
- изолированно анализирует вклад каждого источника задержек (память и ветвления) в тактах процессора;
- по заданному дедлайну определяет, гарантированно ли фрагмент укладывается в жесткие временные ограничения СРВ;
- считывает описание фрагмента кода и параметры процессорной архитектуры из внешнего файла JSON без «магических чисел»;
- выводит детализированную таблицу по операциям и итоговую аналитику в консоль.

## Запуск
```bash
python src/wcet_analyzer.py
```
По умолчанию программа ищет конфигурационный файл по пути data/pid_config.json.

## Структура репозитория
data/        pid_config.json (14 операций ПИД-регулятора с фильтром)
docs/        отчет и графические материалы
src/         wcet_analyzer.py (исходный код программы)
